  5. 2026-11-09智能代理開發者工具

    What Is Eval-Driven Development? How to Improve AI Agents 導讀

    Eval-driven development helps you build AI agents against a consistent set of metrics. Define good behavior, write the eval first, then compare experiments.

    • LangChain 把 EDD 定義成一句話：一邊建 agent、一邊用固定的一組指標量測，然後朝 eval 爬坡；第一步是先寫一份「什麼叫做好」的短規格，包含不該做的事與不能壞掉的行為。
    • 改動要用實驗比較，不能憑感覺：修好一個案例常常弄壞另一個，所以每次改動都必須在同一份資料集上跑過再判好壞。
    • eval 要跑在 CI 與生產環境兩邊，並把線上抓到的失敗案例回灌成新的資料集題目，讓題庫自己長大。
