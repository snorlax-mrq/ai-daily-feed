    Build an AI Code Reviewer with OpenRouter 導讀

    OpenRouter 官方部落格 · 教學

    • 教學提供一支 233 行、只用 Python 標準庫的 review.py，可在本機、Git pre-push hook 或 GitHub Actions 執行：把變更後的完整檔案、測試檔與 diff 上傳到託管的 Linux 沙箱，讓模型實際跑程式重現 bug，而不是只讀 diff 猜。
    • 每一條發現都標記為 confirmed（附上證明指令與輸出）或 unconfirmed（短腳本無法重現的黑洞，例如連線未關、競態），完整報告寫入 .git/ai-review.json，並可用 --apply 把模型提出的 V4A 補丁套回工作區。
    • 技術組合是 Responses API 上三個伺服器工具（Files API 上傳全文、openrouter:shell 開容器跑 Python／SQLite、openrouter:apply_patch 產生補丁）加一個 submit_review 函式工具，用嚴格 JSON schema 確保最終回傳格式。
    • 五個植入 bug 的實測：Claude Haiku 5.5 平均每次 0.0153 美元、125 秒；Sonnet 5.5 為 0.0447 美元、60 秒，三次都修好全部五個 bug；DeepSeek V4.1 Flash 有一次跑滿八回合仍沒交報告，GPT-6 Luna 從未回報被移除的 conn.close()。
    • 限制與成本：沙箱以每秒 0.0001 美元計費，整體約為純 diff 審查的 10 至 40 倍；單次請求上限 20 個檔案（含 diff）、沙箱預設無外網，且變更檔案會上傳到 OpenRouter 與模型供應商，機密程式碼不宜使用。
