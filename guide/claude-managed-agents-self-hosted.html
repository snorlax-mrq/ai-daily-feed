自架 Managed Agents：換的是營運位置，不是安全模型

自架的賣點不是把 sandbox 圍起來，而是把整個控制平面搬回自家網路——安全設計其實沒有換一套。

搬走的是營運位置

Managed Agents 是一組可組合 API，提供 agent harness、sandboxes、credential 處理與 session 歷程，目標是讓長跑型 agent 進生產。

原文的演進分兩步：先在 Claude Platform 上做託管服務，再補上自架 sandbox，給要把程式碼留在自家環境的團隊。

這次整包搬進來：Managed Agents server、它的資料庫，以及跑 shell 與檔案工具的 workers 都由你營運。

推力來自工作量變重。原文列的例子是修壞掉的 build、測 release、分流告警、清 bug backlog，全都無人看管地跑在你的程式碼上。

（編輯推論：權限給到這種程度，託管與自架的差別就從資料落地變成責任歸屬。）

開發者不必改寫法：自架版與託管版用的是同一組 core API。

（編輯推論：四個部分可分別託管或自架，才讓「只自架 sandbox」這種混搭姿態成立。）

三種姿態，四條原則照樣成立

並列選項，原文未給排序；括號是「誰的機房」

A全託管基礎設施 Anthropic 跑，你只寫 agent（Claude Platform）
B只自架 sandbox程式碼留自家環境，控制平面仍託管
C整套自架harness、sandbox、credential、session 全在你家，伺服器與資料庫自營

原文說得很直接：四條原則在 A、B、C 三種情況都適用，包括你自己經營整台服務時。

自架多出來的是營運責任，不是另一套安全設計——原文只用一句話帶過，這卻是選型的關鍵。

只自架 sandbox 夠不夠？原文只給動機

原文對需求的描述停在動機層：agent 的權限大到會碰內部系統時，有些團隊要的是整個服務在自己環境，而不只是 sandbox。

它也補了一句現實——在那之前，這條路等於自己把平台造出來。這次公告要解的就是這件事。

四條原則：限制寫進架構，不靠人盯

原則機制（原語）原文說法與限定
1 分離harness 與 sandboxharness 是 brain、負責呼叫 Claude；sandbox 是 hands、跑 agent 的程式碼；agent loop、session 歷程、vault 的 secret 都留在 sandbox 外
2 credentialvault ＋ sandbox 外的 proxysecret 不進 sandbox；MCP 工具與「支援的」API 呼叫由 proxy 代加；自架時也可以把 credential 另存自家 secrets manager
3 出口allowed hosts 清單可以為每個 environment 設 allowed hosts 清單，清單外的 host 一律封鎖；自架 sandbox 時改設在自家防火牆
4 稽核OpenTelemetry 匯出記錄每一步的工具呼叫與回傳，送到你既有的監控工具，與其他系統的活動並看

→ 可橫向滑動

原文的因果是：agent 無人看管，就不能靠人逐步檢查，所以限制得內建在系統裡。

分離有實際好處：agent 不依賴同一個 sandbox 撐完整場 run，sandbox 有工具要用才啟動。

出口限制寫得最具體——修 build 的 agent，清單上可能就只有你的 git host 與 package registry。

同一條原則有兩個落點：託管時寫在 environment 設定，自架 sandbox 時改設在自家防火牆。

資料留在誰手上

session 歷程存在你自己的資料庫；組織若與 Anthropic 有 ZDR（零資料留存），對送往 Claude 的請求一樣適用，與其他 Messages API 呼叫相同。

（編輯推論：ZDR 保障的是送往 Claude 的請求，不含你自己的資料庫裡留了什麼。）

原文未給資源規格、併發上限、價格與 GA 時間，也未給任何效能或成本數字。

（編輯觀點：自架把成本從 API 帳單換成一個有狀態服務的維運；值不值得，取決於 agent 是否真的碰到內部系統。）

原文在合規上把兩者拉平：託管與自架在 ZDR 上被寫成同一件事，適用範圍都限於送往 Claude 的請求。

（編輯觀點：原文沒談升級、備份與失敗復原；這三件事一旦自營，就落回你家的 on-call。）

帶走三件事

自架不是自造平台。整套 harness 與 API 一起搬，換的是營運位置。

安全靠分離，不靠信任。credential 與 session 留在 sandbox 外才成立。

先算營運帳。伺服器、資料庫、worker 都歸你，原文未給成本。
