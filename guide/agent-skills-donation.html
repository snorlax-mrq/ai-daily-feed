Agent Skills 進基金會：從 Claude Code 的解方到廠商中立的開放標準

30 秒版本

Anthropic 宣布把 Agent Skills——讓 agent 取得專業知識與工作流程的開放標準——捐給 Linux 基金會旗下的 Agentic AI Foundation（AAIF）。標準自 2025 年 12 月發布以來，已有 ChatGPT、Cursor、VS Code 等 70 多個 agent 平台整合，累計 100 萬個 skills、近 2.8 億次安裝；這次連名稱、logo、GitHub 組織與 agentskills.io 網域一併移交，維護者將由 Anthropic、Google、OpenAI 等公司工程師以個人身份擔任，並已提出版本化發布、正式提案流程與安全指引的起步路線圖。

  • Skill＝一個含 SKILL.md 的資料夾：教 agent 特定任務或領域，附上所需腳本與參考資料。
  • 捐的是資產＋治理：名稱、logo、GitHub 組織、agentskills.io 網域；不加入 AAIF 也能照常使用與貢獻。
  • 起步路線圖：版本化發布、正式提案流程、給 skill 撰寫者與安裝者的安全指引。

從 Claude Code 長出來的標準：一個資料夾，一份 SKILL.md

Agent Skills 的起源很具體：Anthropic 在開發 Claude Code 時發展出 skills。原文描述的痛點是——Claude Code 處理一般知識工作沒問題，但常缺真實業務任務需要的程序性知識（procedural knowledge）。解法維持極簡：一個 skill 就是一個資料夾，內含教 agent 特定任務或領域的 SKILL.md，加上它需要的腳本與參考資料。

生長速度說明了為什麼要開放。2025 年 10 月推出後數週內，開發者就在 GitHub 上發布了數千個 skills，並為 Codex、Cursor、OpenCode 寫出 loader；Anthropic 順勢把 Agent Skills 發布為開放標準，放進獨立的 GitHub 組織與專屬網域，讓任何 agent 都能採用。到今天：超過 70 個 agent 平台已整合——包括 ChatGPT、Cursor、GitHub Copilot、VS Code；累計 100 萬個 skills，安裝近 2.8 億次。

交棒 AAIF：繼 MCP 之後，再捐進基金會的標準

這次的受贈方 Agentic AI Foundation（AAIF）隸屬 Linux Foundation，由 Anthropic 與 Block、OpenAI 於去年（2025）共同創立；先前 Anthropic 也把 MCP（Model Context Protocol）捐給了同一個基金會。移交清單包含 Agent Skills 的名稱與 logo、GitHub 組織與 agentskills.io 網域——品牌與入口一併交出。維護模式也寫明：來自 Anthropic、Google、OpenAI 等公司的工程師將以個人身份維護標準，由 David Soria Parra 與 Mahesh Murag 擔任 Lead Maintainers。

不用加入 AAIF 也能用。原文明說：你可以繼續使用這個標準、也可以貢獻，而不必加入 AAIF——捐贈改變的是「誰決定標準走向」，不是使用門檻；標準的開放使用與基金會治理是兩件事。

路線圖第一版：先把治理的骨架立起來

捐贈同時附上一份已提案的起步路線圖，方向都指向治理規範化。與 MCP 相同，專案將持續以社群意見優先、決策透明為原則：規格變更的回饋可在專案 Discord 提出，規格全文在 agentskills.io，討論則在 GitHub。

對規格變更建立正式的提案程序；現階段的回饋入口是專案 Discord——針對提案中的規格變更給意見。

03安全文件

給撰寫者與安裝者的安全指引（security guidance）

對象同時涵蓋 skill 的撰寫者與安裝者——在 100 萬 skills、近 2.8 億次安裝的生態裡，安全指引被列為起步項目。

帶走三件事

採用規模是捐贈的底氣。70+ agent 平台、100 萬 skills、近 2.8 億次安裝——標準早已是事實基礎設施；把治理交給中立基金會是收尾動作，而非冷啟動實驗。

極簡設計養出跨廠生態。一個資料夾＋一份 SKILL.md，簡單到數週內就有人為 Codex、Cursor、OpenCode 等競品 agent 寫出 loader；正因 ChatGPT、Cursor、Copilot、VS Code 都已整合，「廠商中立」才成為必要的下一步。

下一步看提案流程與安全指引落地。路線圖目前的狀態是「proposed」——版本化發布、正式提案、安全指引能否真正運作，才是檢驗社群治理是否成真的觀察點。
