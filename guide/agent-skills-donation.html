Agent Skills 捐進 AAIF：換人治理，不換使用權

Anthropic 把 Agent Skills——給 agent 專門知識與工作流程的開放標準——捐給 Linux 基金會旗下的 AAIF：交出去的是治理權，不是使用權。

skill 的定義刻意壓到最小：一個資料夾，內含教 agent 某個任務或領域的 SKILL.md，再附上它需要的腳本與參考資料。規格全文在 agentskills.io。

痛點講得很直白：Claude Code 處理一般知識工作沒問題，卻常缺真實業務任務需要的程序性知識（procedural knowledge）。標準化要補的就是這一層。

原文結尾是一段致謝：謝謝一開始就用 Agent Skills 的開發者，以及把 skills 帶進自家產品的團隊。其餘入口不變——規格在 agentskills.io，討論在 GitHub。

誰已經在這條標準上

時間尺度才是重點：標準 2025-12 發布、2026-10 捐出，相隔約 10 個月（編輯計算）。

採用不是靠宣告，是靠別人願意替它寫 loader。標準在還沒進基金會之前，就已經被別家產品依賴（編輯觀點）。

捐的是治理，不是使用權

原文一句最該記住：你可以繼續使用這個標準、也可以貢獻，不必加入 AAIF。使用門檻沒動，動的是誰決定下一步。

治理細節目前只寫到這裡：以個人身份參與與兩位 Lead Maintainer。投票規則、任期、任命方式，原文都沒有交代。

同一條路已經走過一次。Anthropic 先前把 Model Context Protocol（MCP）捐給同一個基金會；這次是把相同動作套在 skills 上。

原文用 we've proposed——三項都還在提案狀態，不是已運作的機制。

三個入口分工：規格全文在 agentskills.io、討論在 GitHub、對提案中規格變更的意見在專案 Discord。公告則沒給規格版本號、時程或第三方稽核（編輯觀察）。

帶走三件事

交出品牌與網域才算中立。名稱、logo、GitHub 組織、網域一起移交。
