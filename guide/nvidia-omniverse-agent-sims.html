分工界線：模型指揮，函式庫執行

三個案例的共通結構：開發者用自然語言下指令、審結果、給修正；代理負責把指令翻成組裝資產與接 API 的程式；GPU 函式庫負責物理、RTX 渲染與串流。輪機案的轉子動畫、溫壓流速著色都映射自求解器輸出——視覺是驗證工具，不是裝飾。
