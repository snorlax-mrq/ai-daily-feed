一台專用 Windows 小桌機，把代理與排程任務留在桌上跑：程式碼與檔案不出機器，也不為這些任務付逐 token 的雲端費。

原文的場景很具體：筆電帶出門，桌機上的代理與排程任務照跑。專用機補的是「一直開著」這件事。

工作也不再被一次編輯 session 框住：產生素材、跑長算圖、排程任務，關掉視窗後仍能繼續。

在地端跑支援的模型，處理中的程式碼與檔案留在這台 PC；原文點名的省項，是這些任務的逐 token API 費用。

原文寫的是「支援的模型」：能留在機上跑的是清單內那些，不是任意模型。

原文的定位是「給開發者、創作者與 AI 愛好者的專用 Windows PC」——一台機器服務三種工作，不是只做一件事。

（編輯觀點：成本沒有消失，只是換計價方式——硬體一次付清，電費與維運自己扛。）

原文未給價格、功耗與噪音；對一台要 24 小時開機的機器，這三項與算力同等關鍵（編輯觀點）。

10GbE 對應的是大檔搬運：資料集、模型檔與創作素材，在機器與網路儲存之間來回。

三項賣點分別是 1,200 億參數模型、90GB+ 3D 場景與 4:2:2 影片即時編輯；原文沒給專案規模或對照機種。

少了基準，這些數字只能當上限宣告；夠不夠用，要看自己的工作負載（編輯觀點）。

生態：先讓工具搬家，代理才搬得進來

Premiere 這輪加速的是幾個常用 AI 功能：Enhance Speech、Object Mask、Scene Edit Detection 與 Auto Reframe，改走 TensorRT-RTX。

格式支援同步補齊：Canon RAW、Red RAW、ARRI RAW、ARRICORE、ARRI HDE、MXF 內的 H.264 與 HEVC，以及 ProRes RAW 與 long-GOP。

Photoshop 的 Remove Tool 走 TensorRT-RTX，Camera Raw 改原生上 Arm；原文強調的重點是不必再靠模擬。

創作代理是另一條線：把 Photoshop 這類既有應用與本地 AI 工具接起來，用自然語言指令從想法走到成品。

Blender 這條有硬條件——要 Blender 5.3 加最新的 Game Ready 或 Studio 驅動，換來視窗內接近成品的即時預覽。

在 Adobe MAX，與會者用自然語言指令把草稿變成算圖與動畫，合做一個共用的數位邁阿密景觀。

同一條思路在影片上收尾：Photoshop 與 ComfyUI 由 Hermes Agent 串起來，從隔離主體到生成影片都在裝置上完成。

生成片段還能用 RTX Video Frame Generation 補到 60 fps，再轉 HDR 進調色，整條管線留在一個 ComfyUI 工作流裡。

（編輯推論：真正的分野是代理有沒有自己的機器——共用筆電的代理，壽命等於一次闔蓋。）

（編輯觀點：三塊合起來才是「桌機取代工作站」的實際論證，硬體規格只是前提。）

同一篇裡的幾個平台訊號

Windows ML 這輪開放兩件事：任何 Hugging Face 的 GGUF 模型都能用 llama.cpp 後端在 Windows ML 裡跑。

DxCGC 後端以實驗版釋出，讓遊戲開發者透過 DirectX 12 編譯與執行模型，AI 與繪圖共用同一顆 GPU。

企業端是 DGX Station for Windows 將支援 Windows Server 2028，由 GB300 Grace Blackwell Ultra 桌面超級晶片驅動。

補充清單另點名其中兩項：llama.cpp 推出 v1.0.0；Runway 的 Praxis-1 是 270 億參數的 world action model。

Praxis-1 可在 RTX 5090、RTX PRO 6000 Blackwell、DGX Spark 與 DGX Station 本地跑，並能用 LoRA 微調到自家機器人與相機。

帶走三件事

常駐才是賣點。代理要 24/7 在線，就不該寄生在會被帶走的筆電上。

地端只省「支援的模型」。原文說的是跑本地模型可免逐 token 費用，不是任何任務都免費。

分流比全本地實際。Switchyard 把日常留機上，難題仍回雲端付費。
