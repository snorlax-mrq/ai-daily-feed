摩根大通把 Claude 從工程師推向全公司，真正值得看的是它怎麼把代理關進管線。

四類使用者：從寫程式到寫需求

原文對商業與投資銀行（Commercial and Investment Bank）的效益說得最具體：工作更快進到生產，機構再把騰出的產能重新部署到業務優先事項上。原文未給倍數或時數（原文敘述，無第三方驗證）。

（編輯觀點：「重新部署產能」講的是省下的力氣被移去別的優先事項，不是人力縮減；原文只給這個框架，沒有任何數字支撐。）

原文沒有給人數，只說 Claude 正在全公司推行、範圍超出工程師。使用面可拆成四類，原文並列陳述，未排優先順序。

原文說工程師會把有效的做法彼此分享，但沒說形式與範圍；能確定的只有 PR 審查與 self-healing 兩類用途。

最靠近業務的人也在建。原文給的理由是產品開發有一大段不在寫程式：研究、需求、設計、規劃都發生在程式碼之外。

資產與財富管理（Asset & Wealth Management）走的是組織設計：把最懂業務、最敢提點子的人，與技術及產品專家編成小型授權團隊。

這樣編組是為了更容易客製並規模化交付客戶投資方案。Claude Code 已納入該部門工程流程；原文稱團隊動得更快，同時在交付客戶前把每筆變更送進更嚴格的測試（原文敘述，無第三方驗證）。

上個月，J.P. Morgan Asset Management 宣布一個連接器，把 55ip 的 ActiveTax Technology® 接進 Claude for Financial Advisors，讓稅務考量的投資組合轉換分析進入顧問日常工作。

（編輯觀點：這個做法的重點不是工具，而是把懂業務的人放進交付團隊，而不是留在需求端；編制規模與考核方式原文未提。）

控管：代理不能替自己簽核

約束分四層，原文在這一側寫得比成效更具體。第一層是環境：Claude Code 跑在受控環境，含自建容器化平台 Devspace，位置在機構自家基礎設施上。

控制層原文用語擋掉什麼
執行環境Devspace，機構自建的容器化開發平台，跑在自家基礎設施代理直接取得員工憑證或內部系統
權限存取分階段放寬（原文：access widens in stages）一次到位的全面開放
模型新的 Claude 模型須先過機構自己的核准流程未經核准的模型直接進到生產
交付數千個自動測試與核准閘門；自動閘門只回通過或中止，由 pipeline 強制未過測試與核准的變更直接進生產

分階段放寬與模型核准這兩道，原文都沒給時程或次數；能確認的只有兩道都存在，且先於任何人開始使用。

（編輯推論：模型要先過機構自己的核准，等於把模型更新的節奏交給客戶端決定，而不是跟著 Anthropic 的發布走。）

「Claude 不能簽核自己的工作」是原文最硬的一句：自動閘門只有通過與中止兩種結果，由 pipeline 執行，人仍對每一筆生產變更負責。

（編輯觀點：這頁最可轉移的不是用得多廣，而是「代理不得自我核准」被寫進管線，而不是只寫在規範文件裡。閘門會擋人，公約不會。）

一年內的位移，與兩個待補的缺口

原文收在三個階段的位移：過去一年，摩根大通對 Claude 的用法從軟體工程，擴到網路防禦，再到財務顧問的工具。

原文的定位句是：Claude 在全球最大金融機構之一的控制範圍內運作，這正是 Anthropic 說自己在打造的東西。那是目標陳述，不是驗收結論。

原文也寫，這家機構對 Anthropic 提出的要求，正在形塑它為其他受監管機構打造的產品。

（編輯觀點：這是廠商撰寫的客戶案例，成效全屬單方敘述、沒有第三方驗證；可核對的只有名詞與機制——Devspace、Project Glasswing、55ip 連接器。）

兩個缺口值得追：一是「更快」沒有量化基準，二是自建代理由誰審、怎麼審，原文未交代。

帶走三件事

擴大使用不難，難在不開後門。先隔離環境，才敢放人進來。

「Claude 不能自己簽核」最值得抄。寫進管線的規則才會真的擋住。

客戶案例只能讀機制。快多少、誰審代理，原文都留白。
