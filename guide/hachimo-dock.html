小米把小螢幕做成 Agent 的門面：一句話交辦，桌寵用表情與聲音回報進度。硬體自製成本約 150 元，源碼與物料清單全部公開。

從「錄入方」變成「需求提出方」

專案起點不是造型，而是問題：在辦公場景下語音比打字快上數倍，團隊先想到做結合麥克風與按鍵的語音輸入硬體。

但這條路已經很擠——原文點名 ChatGPT 官方的 Codex Micro，也提到小米自家藍牙遙控器因此重新被看見。

於是團隊往前推一步：按鍵語音仍要動手，更省事的是即時語音，只動口、不動手。

按鍵語音輸入已是最簡單的互動？不是，更自然的是「只動口、不動手」的即時語音常駐桌面的「搭子」，隨時接話
除了優化輸入，創作還有新玩法？原文的期待：把 Vibe Coding 從軟體推到硬體，身邊的嵌入式裝置也能客製化分鐘級組件創作
只能用在程式開發與辦公？家庭是另一個同樣重要的場景透過 xiaomi Miloco 控制家電

定位一旦變成「搭子」，硬體就得有自己的外形、人設與聲音；它同時是助手與監工，任務卡住時要能出聲。

團隊背景也解釋了取捨：這是小米技術委員會下的創新產品小團隊，目標是「新奇酷」，不是再做一個更好用的輸入法。

官方說法收得很克制：把定義 HachimoDock 的空間留給每一位使用者，並稱它只是探索 AI 硬體的開端。

玩法開放，外觀也開放

按鍵、搖桿、語音、觸控四種輸入並用，原文的說法是讓幾乎各類遊戲與工具都能做出來。

組件用自然語言生成、直接跑在機上：原文列了自選股行情（看價格與漲跌）、待辦清單、電腦狀態與 Token 用量儀表板，也有電台、農民曆、番茄鐘與貪食蛇。

遊戲與趣味工具跑的是同一套機制：迷宮、接球、切水果、電子寵物、轉盤、抽籤、擲硬幣、塔羅牌、敲木魚，都能自己改。

電台組件能聽不同城市的節目與每日資訊，工作以外的時間也被算進設計裡。

外觀同樣是可改的介面：鍵帽與外殼可自行列印，讓機身配色與螢幕角色配成一整套。

社群那層才是飛輪：網友做的形象與組件可分享、被別人改進，新手一開箱就有東西可用。

原文的畫面很具體：同一張書桌前，交代電腦做事、叫家裡裝置回應，都是對這隻狗開口。

（編輯推論：實體按鍵與常駐螢幕的價值，是不必先開一個 App；這是它與手機語音助理最大的差別。）

150 元要打折看，開源三件套才是重點

原文只寫「硬體自製成本約 150 元」，未列這筆錢含哪些工序（編輯推論：焊接、組裝與除錯的時間成本另計）；同篇也寫明開發板與螢幕至今漲價、缺貨。

兩件事放在一起，復刻的實際花費可能高於這個數字（編輯推論）。

「支援萬款遊戲」是原文的宣傳語，沒有清單或實測；能確認的是四種輸入加上可自訂組件的能力。

真正降低門檻的是三件套：GitHub 上的軟體源碼、嘉立創平台上的物料清單與結構件模型，再加上組裝教學。

社會面也寫進原文：有人因為它，第一次動手做出屬於自己的 AI 硬體。

帶走三件事

便宜不是賣點，可改才是。源碼加物料清單，讓復刻變成可重複的路。

介面選在情緒上。桌寵的表情與聲音，補的是 Agent 執行時的不確定感。

低價要打折看。零件漲價與缺貨，會把這道門檻往上推。
